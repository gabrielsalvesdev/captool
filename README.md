# CapTool

Um projeto para análise e refatoração de código usando IA.

## Funcionalidades

- Análise estática de código
- Sugestões de refatoração
- Integração com GitHub
- Notificações via Discord

## Como Usar

1. Clone o repositório
2. Configure as dependências
3. Execute os testes

## Contribuição

Contribuições são bem-vindas! Por favor, crie um Pull Request para a branch develop.

## Branches

- `main`: Branch principal de produção
- `develop`: Branch de desenvolvimento
